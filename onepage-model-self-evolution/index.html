01
自我对弈：AlphaZero 范式
Self-Play · 最强棋手是跟自己对弈练出来的

给定游戏规则，模型与自己对弈生成海量棋谱。赢的走法加分，输的走法扣分 —— 纯靠自己迭代，超越所有人类棋谱训练的系统。

当前模型 → 自我对弈 → 生成数据 → 训练更强模型 → 循环…

MuZero 更进一步：连规则都不需要告诉模型，让它自己学环境动态。

  • AlphaZero (Silver et al., 2017) — 围棋/将棋/国际象棋，纯自弈超越 Stockfish
  • MuZero (Schrittwieser et al., 2020) — 无规则自弈，Atari 57 款游戏全 SOTA
  • EfficientZero (Ye et al., 2021) — 样本高效版，2h 训练超越人类
02
自我训练与知识蒸馏
Self-Training · STaR / ReST / SPIN

核心公式：用模型自己生成的数据训练自己。

方法原理论文
STaR 模型生成推理链 → 筛选正确答案 → 微调自己 Zelikman et al., 2022
ReST 批量生成 → 过滤 → 多次迭代 ("Grow & Improve") Gülçehre et al., 2023
SPIN 模型做自己的对手：生成"对手"回复 → 学习击败 Chen et al., 2024
Self-Consistency 多条推理路径投票，多数获胜的作为伪标签 Wang et al., 2023
💡 关键区分：自我训练 ≠ 知识蒸馏。蒸馏需要更大的教师模型；自我训练只用同一个模型，靠多次采样 + 过滤来提升。
03
自我奖励与自我对齐
Self-Rewarding · LLM-as-Judge · Constitutional AI

RLHF 的瓶颈：需要人类标注偏好。自进化方案 —— 让模型自己当裁判。

方法核心思想
Constitutional AI
(Bai et al., 2022)		 用宪法原则约束模型自我修正：生成 → 按原则批判 → 重写。无需人类偏好数据。
Self-Rewarding LM
(Yuan et al., 2024)		 LLM 生成回复 + 评分 + 训练下一代。每轮用最新模型当裁判，奖励信号质量随迭代提升。
SPPO
(Wu et al., 2024)		 Self-Play Preference Optimization：不用外部奖励模型，纯对弈式偏好学习。
⚠️ 关键风险：奖励黑客 (Reward Hacking)
模型可能学会迎合自己的评分标准而非真正变好 —— 等价于评卷人和考生是同一个人。
# Self-Rewarding 循环（简化） for iteration t = 0, 1, 2, ...: D_t = M_t.generate(prompts) # 模型 M_t 生成候选回复 R_t = M_t.evaluate(D_t) # M_t 自己打分 M_{t+1} = DPO(M_t, D_t, R_t) # 用自评数据偏好优化 → 得到更强 M
04
递归自我改进 & 进化算法
Recursive Self-Improvement · Model Merging · Evolution

递归改进 (Recursive Self-Improvement)：模型 V1 训练出 V2，V2 再训练 V3……每代用更强模型生成数据，理论上可无限升级。代表工作：Self-Refine、Reflexion（模型自己反思错误、迭代修正）。

进化算法：不走梯度下降，而是用群体 + 变异 + 选择。

方法要点
Model Soups
(Wortsman et al., 2022)		 多个 fine-tune 模型的权重直接平均，零额外训练，精度超单个最佳模型
Evolutionary Model Merge
(Akiba et al., 2024)		 用进化算法搜索模型融合配方，AutoMerge 自动化合并多模型权重
LLM2LLM
(Lee et al., 2024)		 教师模型(强)生成数据 → 学生模型(弱)学习 → 学生变强后当新教师，自举循环
模型 → 反思/批判 → 修正输出 → 训练下一代

❌ 三大常见误区

✗
自进化 = 不用任何外部数据 👉 自进化仍需初始训练数据 + 任务定义。它只是把"人工标注"换成"模型自标注"，而非完全真空运行。
✗
自进化一定越变越强 👉 模型崩溃 (Model Collapse) 是真实风险：用自己生成的数据反复训练会导致多样性消失、性能退化。
✗
递归改进能无限指数增长 👉 现实中回报递减 (diminishing returns)：每代增益越来越小，且计算成本指数增长。目前 2-3 代后基本持平。
这一页先记住 · TL;DR
核心逻辑
用模型自己生成的信号（数据/评分/反馈）替代人工标注，形成闭环迭代
五条路线
自我对弈 / 自我训练+蒸馏 / 自我奖励+对齐 / 递归改进 / 进化合并 —— 经常相互配合
最大风险
模型崩溃 · 奖励黑客 · 回报递减 —— 自进化不是银弹，需要精心设计约束
一句话总结：模型自进化 = 用 AI 训练 AI，让模型自己生成数据、自己评价、自己迭代升级。 它的上限是"递归自我改进"，它的下限是"模型崩溃" —— 关键在于自监督信号的质量与多样性。
