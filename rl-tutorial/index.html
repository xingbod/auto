STEP 0强化学习是什么

从"试错"出发,看 Agent / Environment / Reward 的闭环。

在开始写代码前,先把强化学习 (Reinforcement Learning, RL) 的核心循环钉死。 它和监督学习的最大区别是: 没有"正确答案"标签, 只有一个滞后的、稀疏的 reward 信号。 Agent 必须靠"试"出好行为,再靠"奖励"把好行为"强化"下来。

Agent
智能体
─── action a ───▶
Environment
环境
◀── reward r + state s' ──

5 个核心要素

  • State s 环境的当前观察 (如 CartPole 的 4 维向量:位置、速度、角度、角速度)
  • Action a Agent 这一步要做的动作 (如左推 / 右推)
  • Reward r 环境的即时打分 (CartPole 每坚持一帧 +1)
  • Policy π(a|s) 状态到动作的映射 (Agent 的"大脑")
  • Value V(s) / Q(s,a) 长期回报的期望 (衡量"这个状态有多好")

和其他学习范式对比

维度监督学习无监督学习强化学习
信号标签 y无reward r
数据i.i.d. 样本i.i.d. 样本轨迹 (有时间相关性)
反馈时机即时—可能延迟 (稀疏奖励)
目标最小化预测误差发现结构最大化累积奖励

STEP 1多臂老虎机 · 探索 vs 利用

没有"状态"的极简 RL,核心矛盾:多挖一点已经知道好的,还是多试试不确定的?

想象面前有 5 台老虎机,每台的"中奖概率"你不知道。 每拉一次,得到一个 reward。目标:拉 1000 次,让累积 reward 最高。

这是 RL 里最简单的 无状态 问题——只看 action→reward,不关心状态转移。 核心问题就是教科书经典的 exploration vs exploitation:

  • Exploit (利用):一直拉目前估值 Q[a] 最高的臂
  • Explore (探索):随机拉别的臂,虽然短期 reward 可能低,但可能发现更好的臂

4 种经典策略

策略核心思想超参
random完全随机,无学习—
ε-greedy (固定)ε 概率随机,否则取 argmax Qε ∈ [0,1]
UCB1给"尝试少"的臂加一个 bonus,鼓励探索c (置信度)
ε-decay前期多探索,后期专注利用ε_start, ε_end, decay
关键公式 · Q 值增量更新
每拉一次臂 a 得到 reward r,Q 值的更新是"新样本均值": 
Q[a] ← Q[a] + (r − Q[a]) / N[a]
等价于 Q[a] = (1 − 1/N[a]) · Q[a] + (1/N[a]) · r,即所有历史 reward 的平均。

STEP 2Q-Learning 表格型

加入"状态"——Agent 不仅看 reward,还要看"我在哪"。

Bandit 只有一个状态,真实问题里 状态会变。 这一步引入 RL 的核心数学结构: 马尔可夫决策过程 (MDP)。

MDP 五元组 (S, A, P, R, γ)

  • S:状态集合 (FrozenLake 4×4 有 16 个格子)
  • A:动作集合 (4 个方向)
  • P(s'|s,a):状态转移概率 (在 FrozenLake 里"is_slippery=True" → 走一步会随机滑向左右)
  • R(s,a,s'):奖励函数 (到 G 得 +1,其它 0)
  • γ ∈ [0,1]:折扣因子,衡量未来 reward 的现值

Bellman 最优方程 (Q 形式)

Q*(s, a) = E[ r + γ · max Q*(s', a') | s, a ]

它说:状态 s 下做动作 a 的"长期价值",等于"立刻拿到的 r"加上"到达 s' 之后按最优策略能拿到的折现价值"。

Q-Learning 更新规则 (时序差分 / TD)

Q(s, a) ← Q(s, a) + α · [ r + γ · max Q(s', a') − Q(s, a) ]

其中 α 是学习率,方括号里就是 TD 误差。这是 off-policy 的: 用的"目标"是 max (假设下一步会选最优动作),但行为可以 ε-greedy 探索。

STEP 3DQN · 深度 Q 网络

状态多到表格装不下时,用神经网络拟合 Q 函数。

Q-Learning 在小状态空间 (FrozenLake 16 状态) 没问题, 但 CartPole 的状态是 4 维连续向量,理论上无穷多状态——Q 表根本建不出来。 DQN (Deep Q-Network, Mnih 2013, Nature) 用一个神经网络 Q(s, a; θ) 拟合 Q 表。

DQN 三大件 (原论文贡献)

Environment ─── s, r, done ───▶ Q-Network θ (online)
Replay Buffer D ←── (s, a, r, s', done) ── Environment
Q-Network θ ─── sample batch ──▶ MSE Loss ─── target ──▶ Target Q-Network θ⁻
每 C 步把 θ 复制到 θ⁻
  • ① Replay Buffer (经验回放):把 (s,a,r,s',done) 存进固定大小的循环队列, 训练时随机采样 batch。
    解决:相邻样本强相关 → 训练不稳定 (类似 SGD 需要 i.i.d.)
  • ② Target Network (目标网络):用一份"老"参数 θ⁻ 算 TD 目标, 每隔 C 步才把 θ 同步过去。
    解决:TD 目标和当前网络都在变 → "移动靶"问题
  • ③ ε-decay:动作选择仍用 ε-greedy,但 ε 从 1.0 指数衰减到 0.05

DQN 损失函数

L(θ) = E_{(s,a,r,s') ~ D} [ ( r + γ · max Q(s', a'; θ⁻) − Q(s, a; θ) )² ]

对当前网络 θ 求梯度,target 网络 θ⁻ 不参与反向传播 (设 requires_grad=False)。

STEP 4REINFORCE · 策略梯度

不估计 Q,直接优化策略 π(a|s; θ)。

DQN 是 value-based:学 Q(s,a),策略是 argmax Q 的副产品。 还有一类 policy-based 方法:直接用一个网络 π(a|s; θ) 输出动作概率, 对 θ 沿"增加高 reward 轨迹出现概率"的方向做梯度上升。

REINFORCE 核心公式 (Williams 1992)

∇θ J(θ) = E_τ [ Σ_t ∇θ log π(a_t | s_t; θ) · G_t ]

其中 Gt 是从时刻 t 开始的折扣累积回报。 直觉:把高回报轨迹上出现过的动作概率推高,低回报轨迹上出现过的推低。

完整算法 (回合制)

  1. 用当前策略 π(·|; θ) 跑一个完整 episode,记录 (st, at, rt)
  2. 从后往前算每个时刻的折扣回报 Gt = Σk≥t γk-t rk
  3. loss = − Σt log π(at|st; θ) · Gt (对 θ 求梯度下降)
  4. θ ← θ − lr · ∇loss

为什么 log π · G 是对的? (Policy Gradient Theorem)

完整证明见 Sutton & Barto 第 13 章。简单直觉: log π(a|s;θ) 对 θ 的梯度方向是"提高选 a 概率"的方向; 乘上 G (回报越大,权越大),等价于"用高回报样本加权提高对应动作的概率"。

STEP 5PPO · 信赖域策略优化

REINFORCE 太抖,PPO 用"裁剪"让更新更稳。

REINFORCE 最大的问题是 高方差——一次失败的 episode 可能让策略崩溃。 PPO (Proximal Policy Optimization, Schulman 2017) 是 OpenAI 提出的工业级方案, 核心想法:限制新旧策略的差距,别一次步子迈太大。

PPO-Clip 目标函数

L_clip(θ) = E_t [ min( r_t(θ) · Â_t,  clip(r_t(θ), 1−ε, 1+ε) · Â_t ) ]

其中 r_t(θ) = π_θ(a_t | s_t) / π_old(a_t | s_t)   (新旧策略的"概率比")
  • Ât:优势函数,衡量"在 st 做 at 比平均好多少"
  • clip:把 rt 截到 [1-ε, 1+ε] (典型 ε=0.2),阻止概率比跑太远
  • min:取"未裁剪目标"和"裁剪目标"较小者,避免过度优化

PPO 的 Actor-Critic 结构

State s ──▶ Actor (policy head) ──▶ π(a|s) → action
State s ──▶ Critic (value head) ──▶ V(s) → baseline
共享 backbone,两个输出头;Â = G − V(s) (GAE 做平滑)

为什么 PPO 是工业默认?
  • 实现比 TRPO 简单 (不用共轭梯度 / KL 约束)
  • 比 REINFORCE / A2C 稳定 (clip 限制步长)
  • 兼容离散 / 连续动作 (ChatGPT RLHF 第一阶段就是 PPO)
