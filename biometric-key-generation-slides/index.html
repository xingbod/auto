┌─────────────────────────────────────────────────────┐ │ 生物特征密钥生成 (Biometric Key Generation, BKG) │ │ = 从生物特征稳定地生成/释放一段加密密钥 │ │ 「不可遗忘、永不丢失、终生不变」 │ └─────────────────────────────────────────────────────┘ ↓ ↓ ↓ 三大量身目标 ① 稳定性 (Reproducibility) ← 同一用户多次采集 → 同一密钥 ② 安全性 (Security) ← 模板不可逆、不可链接、抗攻击 ③ 可撤销性 (Revocability) ← 模板泄露后可以重新签发

为什么 BKG 重要？

传统密码学密钥靠"记住"或"存住"，生物特征密钥靠"长在身上"——但生物特征 有噪声、隐私敏感、终生不变。这三大特性是 BKG 所有技术挑战的根源。

2.1 BKG 三大目标（ISO/IEC 24745 标准）

① 稳定性 Reproducibility

同用户多次生物采集 → 同一密钥

挑战：传感器噪声、姿态变化、年龄、表情...

解决：纠错码（BCH、RS、Polar） + Secure Sketch

② 安全性 Security

模板不可逆、不可链接、抗攻击

挑战：Inversion / Linkability / Replay 攻击

解决：不可逆变换 + 多因子 + Challenge-Response

③ 可撤销 Revocability

泄露后换 token 重新生成

挑战：泄露后无法恢复原生物特征

解决：Cancelable Biometrics + BioHashing

核心矛盾

稳定性需要"匹配"原始生物特征 → 安全性需要"不暴露"原始生物特征 → 这两个目标天然冲突。

这正是 2023-2026 整个研究领域的核心张力：如何在保证稳定性的同时保护生物特征隐私？

代表 2：Multi-Factor Fuzzy Extractor (2024-05)

Tran, Hu, Hu · arXiv:2405.11456

🎯 核心问题

传统 Fuzzy Extractor 容易被模仿攻击：一旦攻击者捕获有效生物特征，方案不再安全。

传统 FE

只有 1 个因子（生物特征）

单点失败 = 系统崩溃

Multi-Factor FE

生物特征 + 密码 / 智能卡

抵抗捕获+重放攻击

核心创新

把密码和生物特征做密码学绑定

丢失任一因子 ≠ 泄露

🔗 启示

  • 与 Authenticated Key Exchange (AKE) 协议融合形成端到端方案
  • 适合延伸：①多模态（多生物特征） ②与 TEE 集成 ③抗侧信道
  • 目标会议：USENIX Security / CCS / TIFS

📚 综述覆盖五大维度

🔍 关键 insight

"Deep learning has revolutionised the field of pattern recognition, including biometric recognition. Apart from breakthrough advances in terms of biometric performance, the use of deep learning was reported to impact different covariates of biometrics such as algorithmic fairness, vulnerability to attacks, or template protection."

8.1 论文写作技巧（从顶刊编辑角度）

📝 TIFS/TDSC 评审最看重的 5 点

  1. 安全分析的形式化：UC 框架 / Game-based proof / 攻击者模型
  2. 至少 3 种攻击：Inversion + Linkability + Replay，少一个直接 reject
  3. 跨数据集泛化：至少 3 个公开数据集，不能只在自己数据上跑
  4. 公平对比：所有 baseline 在同一硬件/超参下重新训练
  5. 代码开源：附 GitHub 链接，审稿人可复现

📊 实验部分的标准结构

① 数据集

≥3 个公开数据集

LFW / CASIA / IJB-C / MOBIO / VGGFace2

② Baseline

≥5 个 SOTA 方法

BioHash / IoM / PolyProtect / FaceNet / ArcFace

③ 评价指标

≥6 个指标

FAR/FRR/GMR/EER/FMR100/ZeroFMR + ASR + BER

11. 总结：5 句话回顾

  1. 范式转移：从 Handcrafted+ECC → DL 端到端+Neural Decoder，WiFaKey 是分水岭
  2. 蓝海方向：可穿戴/IoT 场景（耳道/PPG/ECG/BCG）2025-2026 爆发，是发文好窗口

  4. 新范式：Challenge-Response（ChaRVoC）+ 多因子融合是 2026 新范式
  5. 新场景：AI Agent/数字实体的生物特征身份（2026 新兴，竞争小）
