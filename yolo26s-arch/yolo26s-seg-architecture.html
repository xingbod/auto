task=instance segmentation · backbone→neck→head · 11.5M params

SPPF / Proto / Training 元素
Neck (PANet FPN+PAN) · Sem loss
Head 主体 (回归/分类/Mask)
1-to-1 e2e Head (NMS-free)
1-to-Many Head (训练辅助)

Backbone (P1/2 → P5/32)

  • Stem: 2× Conv 3×3 s=2 → 320×320×64, 160×160×128
  • 4× C3k2 模块,带 e=0.25 / csp=True 两种配置
  • SPPF k=5 提感受野
  • C2PSA ×2 = PSA 注意力 (Position-Sensitive)

Neck (PANet)

  • FPN top-down: P5 up×2 → concat P4 → C3k2 512
  • 继续 up×2 → concat P3 → C3k2 256 (P3 out)
  • PAN bottom-up: P3 down → concat P4_n → C3k2 512 (P4 out)
  • P4 down → concat P5_n → C3k2 1024 (P5 out)

Head · Segment26

  • Box 分支: DFL-free, reg_max=1, 轻量化
  • Class 分支: BCE, Task-Aligned Assigner
  • Mask 系数: 每实例 32 维
  • Proto: P3/P4/P5 多尺度融合 → 256×640×640
  • 辅助 Sem seg loss 提升收敛

Dual Detection Head

  • 1-to-1 (默认): NMS-free e2e, (N,300,6), 部署友好
  • 1-to-Many (辅助): 传统 YOLO 输出, 训练监督用
  • export / predict / val 时可切换 end2end=False

Training Recipe

  • MuSGD: SGD + Muon 混合优化器
  • Progressive Loss: 训练重心渐进迁移到推理头
  • STAL: 小目标正样本覆盖增强(细胞任务关键)
  • Sem seg aux loss: 提升 mask 边界质量

细胞分割场景适用性

  • STAL + Sem loss 对小目标/密集细胞友好
  • DFL-free 简化部署(嵌入式显微镜/Cell 计数硬件)
  • NMS-free e2e 减少后处理耗时 → 实时分析可行
  • 多尺度 Proto 适合不同尺寸细胞(2-200px 共存)
  • CPU ONNX 比 YOLO11n 快 43% (YOLO26n 参考值)
