图像生成三大技术范式

GAN 生成对抗网络

核心：生成器 vs 判别器的博弈

2014 Goodfellow · 隐式密度估计
优点：推理快、图像清晰
局限：训练不稳定、模式坍塌、多样性不足

噪声z→生成器G→判别器D

Diffusion 扩散模型

核心：逐步去噪还原图像

2020 DDPM · 似然模型
优点：生成质量高、训练稳定
局限：推理慢（多步采样）

x₀→+噪声→xT→去噪→x̂₀

Flow Matching 流匹配

核心：学习速度场，直线路径

2023-24 · 连续归一化流
优点：路径更直、采样更快
代表：SD3、Flux

噪声→vθ(x,t)→数据

此外还有 Autoregressive 自回归模型（DALL-E 1, Parti），将图像 token 化后逐 token 预测

GAN 架构原理

生成对抗网络：两个网络博弈——生成器伪造、判别器鉴别

G(z) ↘
真实样本

D(x) → 真/假
[0,1]
minG maxD Ex[log D(x)] + Ez[log(1 − D(G(z)))]

训练困境：当 D 太强 → G 梯度消失；D 太弱 → G 不进步。需要精心平衡

DDPM：扩散模型复兴 (2020)

Jonathan Ho, Ajay Jain, Pieter Abbeel · UC Berkeley · NeurIPS 2020

核心思想：两阶段过程

① 前向扩散（加噪）

xt = √(ᾱt)·x0 + √(1−ᾱt)·ε
t=1,...,T / T=1000 / 固定马尔可夫链

从清晰图像逐步添加高斯噪声
最终 xT ≈ N(0,I)

② 逆向去噪（生成）

εθ(xt, t) → 预测噪声
xt−1 = 从 xt 去除预测噪声

U-Net 学习预测每一步添加的噪声
逐步去噪还原 x0

训练目标

Lsimple = Et, x₀, ε[ ||ε − εθ(xt, t)||² ]

简单而优雅：让网络预测 噪声 而非直接预测图像。训练稳定、生成多样。

局限：像素空间扩散 → 计算量大（1024×1024 需大量 GPU 内存）

Classifier-Free Guidance (CFG)

ε̂θ(xt, c) = εθ(xt, ∅) + w · [εθ(xt, c) − εθ(xt, ∅)]

w > 1 增强文本对齐，但过高会产生过饱和伪影。典型值：7.0–9.0

Flow Matching / Rectified Flow (2023–2024)

下一代生成范式——更简单、更直的生成路径

从扩散到流匹配

传统 Diffusion (DDPM)

• 噪声 → 数据的随机路径（弯曲）
• 需要 50-1000 步采样
• 训练目标：预测噪声 ε

Rectified Flow / FM

• 噪声 → 数据的直线路径
• 仅需 4-20 步即可高质量生成
• 训练目标：预测速度场 vθ

核心公式

xt = (1−t)·x0 + t·ε   直线插值路径
LFM = Et,x₀,ε[ ||vθ(xt, t) − (ε − x0)||² ]

关键直觉：不预测噪声，而是预测从噪声指向数据的速度方向。路径越直，采样越快

DreamBooth (2022.08)

Nataniel Ruiz et al. · Google / BU
CVPR 2023 Best Student Paper

方法：用 3-5 张主体照片 + 稀有 token
(如 "sks") 微调整个模型 → 新场景中生成该主体

Hu et al. · Microsoft (2021)

• 可叠加：lora1 + lora2
• 训练快：消费级 GPU 几分钟

发展脉络总结

🔄 架构演进主线

GAN (对抗博弈) → Diffusion (逐步去噪) → Latent Diffusion (潜空间) → Flow Matching (直线路径) → GPT Native (统一多模态)

从隐式→显式、像素→潜空间、弯曲→直线、专用→统一

🔧 骨干网络演进

CNN (DCGAN) → U-Net (DDPM/SD) → DiT (Sora) → MMDiT (SD3/Flux)

从卷积归纳偏置 → 全注意力通用架构

⚡ 采样效率之路

1000 步 (DDPM) → 50 步 (DDIM) → 20 步 (DPM) → 4 步 (LCM) → 1-2 步 (蒸馏/SD Turbo)

从分钟级到毫秒级

🌐 生态与开放性

全闭源 (DALL-E/Imagen) → 社区许可 (SD1.5/SDXL) → Apache 2.0 (Flux schnell, Ideogram 4.0, HiDream)

开源社区推动可控生成、个性化、部署等下层创新

课堂讨论题

Q1: 为什么 Latent Diffusion 比 Pixel Diffusion 更实用？
潜空间压缩 48× 大幅降低计算和内存。但 VAE 的信息损失也限制了细节生成——这是否有上限？
Q2: Flow Matching 为什么能比 DDPM 采样更快？
直线路径 vs 弯曲路径，意味着 ODE 求解器可以用更少的步骤。但这是否以生成多样性为代价？
Q3: 开源 vs 闭源——谁在推动图像生成技术进步？
开源生态催生了 ControlNet、LoRA 等创新；闭源模型在质量和安全性上领先。未来会趋向两极分化还是融合？
Q4: GPT 原生图像生成是否代表终局？
统一多模态消除了文本↔图像的转换损耗，但在专业性（如设计工具、精准控制）上仍有欠缺。专用模型还有空间吗？
Q5: 图像生成模型对底层视觉研究的启示？
扩散先验用于图像复原、超分辨率；ControlNet 的空间感知可用于弱监督分割；生成-判别联合训练等
