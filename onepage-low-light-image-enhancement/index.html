01

暗光图像长什么样?—— 3 大物理成因

PHYSICAL CAUSES

夜晚/室内/逆光场景下, 相机 光子数不足 带来 3 个连锁问题:

🔅 亮度坍塌
光子数 少 100× 以上, 像素值集中在 0-30 区间, 视觉上 「一片黑」。
🎲 噪声放大
读出噪声 (高斯) + 散粒噪声 (泊松) 同时浮现, 暗部 噪点明显。
🎨 颜色偏移
Bayer 阵列的 R/G/B 通道响应不均, 暗部偏绿/偏紫。
🔍 细节丢失
高频纹理 (头发/文字/纹理) 被噪声淹没, 拉亮后才发现"糊了"。
⚙️ 核心物理关系 (信噪比公式)
SNR ∝ √I0 · t —— 光子数 I0 越少, 信噪比衰减越快
增强的本质: Y = f(X | θ) 在 低 SNR 区域 做 保边去噪 + 亮度恢复 的联合估计

传统方法:Retinex 理论 (1971) + 4 大经典

RETINEX THEORY

Edwin Land 1971 提出 Retinex 假设: 观测图像 = 反射率 × 光照, 增强的本质是 估光照 → 反射率重构 → 提亮。

03

深度学习:3 大范式 (2017-2024)

THREE DL PARADIGMS

从 端到端监督 → 无参考无监督 → Retinex + 网络融合, 3 范式各有适用场景:

1 端到端监督 SUPERVISED
成对数据 (X, Y) 直接学 X → Y 的映射, 损失函数 L1 + SSIM + VGG perceptual。
代表: LLNet (2017) · MBLLEN (2018) · MIRNet (ECCV 2020) · SNR-Aware (CVPR 2022)
2 无参考/无监督 UNPAIRED
不需要成对数据, 用 GAN 对抗 或 曲线估计 直接优化 无参考指标。
代表: EnlightenGAN (2019) · Zero-DCE (CVPR 2020) · Zero-DCE++ (TPAMI 2021)
3 Retinex + 网络融合 DECOMPOSE+NET
把 Retinex 分解 嵌进网络: 分解网络 + 反射率增强 + 光照调整, 可解释 + 高性能。
代表: RetinexNet (BMVC 2018) · KinD (MM 2019) · SCI (CVPR 2022)
📊 3 范式选型对比
维度 端到端监督 无参考无监督 Retinex+网络
数据 需要成对 (X,Y) 不需要成对 成对/半监督均可
PSNR/SSIM 最高 (有真值) 中等 高 + 可解释
推理速度 中-慢 (大模型) 最快 (曲线法) 中 (两阶段)
代表选型 精度优先/科研 移动端首选 产品级平衡
04

前沿:扩散模型 + 视频 + 文本引导 (2023-2026)

FRONTIER · 2023-2026

2023 起, 暗光增强从「单图回归」走向 「生成 + 引导 + 视频时序」 三条新赛道:

🌫️ 扩散 + 物理先验 DIFFUSION + PRIOR
Diff-Retinex (2023) 把 Retinex 分解嵌入扩散过程, 物理约束 防幻觉; DiffLight (2024) 渐进式生成。
✍️ 文本/指令引导 TEXT-GUIDED
InstructPix2Pix 用自然语言描述目标亮度/风格; PromptIR 软提示注入暗光增强网络。
🎬 视频暗光增强 VIDEO LLIE
StableLLVE (2023) 加 时序一致性损失, 帧间不闪烁; DiffLL (2024) 扩散+光流补偿。
🤖 大模型/全任务 FOUNDATION MODEL
LLM-Retinex (2024) 用 LLM 解析用户意图生成增强策略; 端到端 图像恢复大一统。
📅 2017 → 2026 关键里程碑
📊 4 大评测指标: 传统 PSNR / SSIM (成对) · 无参考 NIQE / LPIPS (感知)。
📂 主流数据集: LOL (485 对) · LOL-v2 · SICE · MIT-Adobe FiveK · SID · SDSD (视频) · LSRW。

新手最常踩的 4 个坑

COMMON PITFALLS
✗
"亮度拉满就行" 👉 PSNR 高 ≠ 视觉好。暴力提亮会同时放大噪声、丢失细节、出现色彩断层。先去噪再提亮, 或联合优化。
✗
"只去噪不增亮 / 只增亮不去噪" 👉 暗光增强 = 增亮 + 去噪 联合任务。分离优化会互相干扰 (提亮暴露噪声, 去噪吃掉暗部)。
✗
"扩散模型一定最强" 👉 推理慢 50-100×。Diff-Retinex 在 T4 上 0.5s/张, 而 Zero-DCE 只需 1ms; 移动端/实时场景请选轻量方案。
✗
"用 LOL 训练就能上线" 👉 LOL 仅 485 对, 极易过拟合。需: ① 合成数据 (SID/RAW) ② 随机裁剪/翻转/色彩抖动 ③ 在测试集上做交叉验证。
