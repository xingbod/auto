4 大核心能力:从感知到生成的闭环

PERCEIVE · REASON · GENERATE · 4D

空间智能的 4 个能力, 构成 感知 → 推理 → 生成 → 4D 动态 的能力阶梯:

👁️ 3D 感知 PERCEIVE
从 2D 图像推断 3D 结构: 深度估计、点云、相机位姿。
2D 图像 → 深度图 / 点云 / 3DGS
🧠 3D 推理 REASON
理解 空间关系 + 物理直觉: 上下左右、碰撞、支撑。
3D 场景 + 任务 → 空间问答 / 路径
🎨 3D 生成 GENERATE
从 文本/图像生成 3D 资产: 物体、场景、建筑。
text / image → 3D 网格 / 3DGS
⏱️ 4D 动态 4D DYNAMIC
3D + 时间: 动态 3D 重建、视频生成 3D、物理仿真。
视频 / 仿真 → 动态 3D 场景

05

新手最常踩的 4 个坑

COMMON PITFALLS
✗
"空间智能 = 3D 视觉" 👉 3D 视觉只是感知。空间智能还包括推理 + 生成 + 4D, 是更广的能力集合。
✗
"NeRF / 3DGS 已经够好" 👉 难编辑、难动画、慢渲染。3D 资产进入工业流程还要解决格式互转、纹理、UV 拆分。
✗
"用 LiDAR 就够了" 👉 LiDAR 贵、稀疏、室外为主。视觉方案 (单图 / 视频 → 3D) 才是室内 + 普惠方向。
✗
"4D 生成 = 视频生成" 👉 视频是 2D + 时间, 4D 是 3D + 时间。Sora 是视频, 不是 4D —— 4D 多了"可从任意视角看"的特性。
