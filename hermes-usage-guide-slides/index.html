3. 科研场景 ① · 每日论文跟踪

使用 skill

research academic-daily-digest

数据源

  • Hugging Face Daily Papers API
  • arXiv RSS (cs.CV / cs.CL / cs.LG)
  • Semantic Scholar / OpenAlex

典型产出

  • 每日 10-20 篇策展论文
  • 中英对照标题 + 摘要
  • 可按 topic / author 过滤
  • 直接 cron 06:00 推到邮箱
cron 06:00→ 抓 HF + arXiv→ LLM 摘要/翻译→ himalaya send→ QQ 邮箱
"省 30 分钟/天：不用每天刷 arXiv，每天早上看到策展好的 10 篇高质量论文。"

6. 科研场景 ④ · 论文精读 (PDF 视觉阅读)

使用 skill

pdf-vision-reading (root)

research arxiv

vision_analyze 工具 + arxiv 抓 metadata + 阅读整篇 PDF

能力

  • 直接读 PDF 图表 (跳过 OCR)
  • 识别论文 Fig. 1 / 架构图 / 实验曲线
  • 提取公式 + 复述方法
  • 跨页合并理解 (context 装不下时分批)

典型用法

  • 快速过：摘要 + Fig.1 截图 → 30 秒知道做什么
  • 深读：分段读 + 写笔记 (research-paper-writing)
  • 对比：3 篇同方向论文并排摘要
  • 复现：从 method 段提取伪代码
"省 2 小时/篇：以前读一篇 10 页 paper 至少 1.5 小时，现在精读 30 分钟就能复述方法 + 找创新点。"

7. 科研场景 ⑤ · 实验代码 (Jupyter Live Kernel)

使用 skill

data-science jupyter-live-kernel

stateful Python REPL，跨 cell 保留变量、import、文件句柄

能力

  • 迭代式数据分析 (不像 execute_code 每次重启)
  • 直接读 .csv / .parquet / 训练模型
  • 画 matplotlib/plotly 图，下载到本地
  • 适合探索性数据 + baseline 验证

典型用法

  • 数据探索：丢一个 xlsx，30 秒出分布图 + 异常点
  • 快速 baseline：调 sklearn / xgboost / 简单 NN
  • 结果可视化：loss 曲线 / 混淆矩阵 / attention map
  • 配合 execute_code：前者 interactive，后者批处理

例："用 jupyter-live-kernel 跑这个 iris 数据集,出 4 个特征的 pairplot + 一个随机森林 baseline"。

18. skills 选择决策树

不确定用哪个？按以下 4 步决策：

① 信息类 (我要"知道") │ ├── 每天都要看 → academic-daily-digest + cron ├── 一段时间趋势 → conference-trend-analysis / blogwatcher ├── 某方向系统 → academic-topic-survey ├── 单篇精读 → pdf-vision-reading └── 历史对话 → session_search
② 产出类 (我要"做出来") │ ├── 长报告 slides → html-teaching-slides ├── 一页速查 → onepage-infographic ├── 架构图 → architecture-diagram ├── 数学动画 → manim-video ├── PPT 文件 → powerpoint └── 论文初稿 → research-paper-writing
③ 实验类 (我要"算出来") │ ├── 数据探索 → jupyter-live-kernel ├── 快速原型 → execute_code ├── LLM 微调 → unsloth / axolotl ├── 推理服务 → vllm / llama-cpp ├── benchmark → evaluating-llms-harness └── 实验追踪 → weights-and-biases
④ 教学类 (我要"教别人") │ ├── 备课 slides → html-teaching-slides ├── 概念图 → onepage-infographic ├── 课堂评估 → audio-teaching-eval ├── 错题整理 → ocr + onepage-* └── 教学设计 → design-md

19. 总结 · 把 Agent 用成"超能力"

机制是"心脏"，skills 是"专业工具包"——机制让你"能动"，skills 让你"动得快、动得准"。

5 条核心心法

  1. 先看机制再选 skill：知道 Agent 能做什么，再映射到 skill
  2. 组合优于单一：3 个 skills 串联 = 一个端到端工作流
  3. 数据流是核心：PDF/CSV/JSON → skill 加工 → slides/报告
  4. 复用工作流：把"科研端到端" / "教学端到端" 当模板
  5. 实测再下结论：每个 skill 自己跑一遍，比看文档靠谱

推荐学习路径 (4 周)

W1: html-slides + onepage → W2: cron + digest → W3: topic-survey + pdf → W4: jupyter + unsloth
