01什么是 TTA?为什么需要它?
What & Why

训练集与测试集往往分布不同(corruption / domain / style shift),直接上线会让精度骤降。传统做法是重新标注新数据 → 重新训练,代价昂贵且不现实。

TTA = 模型部署后,在推理时仅利用测试样本自身的信号(预测熵、自监督损失等)调整模型少量参数,以对抗当下的分布偏移,全程不接触源数据、不需要标签。

TTA 形式化定义 θ' = argminθ  Lself( xtest ; θ ),    不需要 ytest
其中 Lself 可以是熵 H( pθ(y|x) ) 或自监督辅助任务损失
02TTA 的方法谱系:两条主轴
Taxonomy by Two Axes

所有 TTA 方法都可以沿参数更新范围与数据流方式两条主轴分类:

轴类别说明
按
更新范围
(What)		 Full TTA所有模型参数都可更新,灵活但易过拟/遗忘
BN-only只更新 BatchNorm 的 γ/β 和均值方差 (如 TENT、SAR),参数量极少最常用
Partial / Layer-wise只更新特定层 (affordance layers),其余冻结
Source-Free不需要源训练数据 (只发模型权重给下游),适配隐私受限场景
按
数据流
(How)		 Single-sample一次一个样本即时调整,最难但最实用
Batch-based成批涌入时利用 batch 统计更新,精度高但依赖 batch size
Continual / Streaming处理流式数据,需主动防灾难性遗忘
Online TTA逐样本即时调整同时输出预测,延迟与精度需兼顾
两条轴的自由组合 例: TENT = BN-only × Batch-based  |  CoTTA = Full × Continual  |  SAR = BN-only × Batch
03经典方法横向对比
4 Representative Methods
方法 / 年份 核心思想 标签需求 主要局限
TTT (2020)
Sun et al., ICML		 训练时附带自监督头 (如旋转预测);推理时用自监督损失更新该子网络 无 需在源域重新设计并训练自监督辅助任务
TENT (2021)
Wang et al., ICLR		 最小化预测分布的熵 H( pθ(y|x) ),只更新 BN 参数 无 强依赖 batch 统计;错预测会自我强化
CoTTA (2022)
Wang et al., CVPR		 教师-学生 + 随机恢复 + EMA,长期持续适应,同时防遗忘与误差累积 无 全参数更新,计算开销大
SAR (2023)
Niu et al., ICLR		 锐度感知最小化 + 限制 BN 势能,在噪声偏移下更稳健 无 仍需 batch,大模型上 BN 层稀疏
TENT 的核心损失 (无监督) LTENT( x ) = - Σc   pθ( c | x ) · log pθ( c | x ) = H( pθ(y|x) )
只对其求梯度并更新 BN 的 γl, βl 两个参数张量
04两大命门:误差累积与灾难性遗忘
Error Accumulation & Catastrophic Forgetting

TTA 用没有标签的预测信号做训练,这带来了两个根本风险:

挑战现象主流缓解方案
误差累积
Error Accumulation		 高置信的错误样本反过来又"训练"模型,越改越偏,精度快速退化 置信度阈值过滤 / 只更新低熵样本 · SAR 的锐度约束 · CoTTA 随机恢复权重
灾难性遗忘
Catastrophic Forgetting		 逐渐适配新域后,模型在源域(或之前偏移)上的能力被覆盖 EMA 老师网络保持旧知识 · 权重正则 ‖θ-θ0‖² · 随机重置部分权重到 θ0
Batch 依赖
Batch-size Sensitivity		 BN-only 派方法需要足够大的 batch 才能算出可靠的均值/方差 替换为 GroupNorm / LayerNorm · 设计单样本损失 · 维护可学习的统计 EMA
关键权衡 适应强度 ↑  →  应变力 ↑ 但稳定 ↓   |   更新频率 ↑  →  遗忘 ↑
所有 TTA 工程化设计的本质都是在「适应」与「保持」之间走钢丝
⚠ Common Pitfalls · 4 个理解误区
✗
TTA = 重新训练 用测试域数据微调节全部参数
👉 TTA 在推理阶段仅用测试样本自身的自监督 / 熵信号更新极少参数,不接触源数据
✗
所有模型都能直接接 TTA 接个 TENT 就有效
👉 主流 BN-only 派要求模型有可用的 BN 层;ViT / 无 BN 架构需改用 GroupNorm 适配或换方法
✗
越适应越准确 让模型充分拟合测试域
👉 错误预测会自我强化(误差累积);必须设置信过滤、熵阈值、可更新频率上限
✗
TTA 能完全替代 Fine-tuning 用 TTA 就不用再标数据了
👉 TTA 只应对小型 / 中度偏移;严重域差异仍需少量标注 + 有监督微调
★ TL;DR · 3 个要点先抓牢
What

推理期用测试域样本的无监督信号(熵 / 自监督损失)更新少量参数,不重训、不要标签

How

两条主轴:BN-only vs Full,Single / Batch / Continual;TENT、CoTTA、SAR 是三个范式代表

Watch

两大命门:误差累积与灾难性遗忘;置信过滤 + EMA + 随机恢复是工程标配

TTA 让模型在推理阶段"临场应变":通过最小化自监督信号调整少量参数,
在不重训的前提下对抗分布偏移 —— 但必须在「适应力」与「稳定性」之间走钢丝
