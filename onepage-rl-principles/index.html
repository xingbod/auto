01

RL 是什么？和监督学习有什么本质区别？

VS. SUPERVISED LEARNING

监督学习是 「看答案做题」，每道题都标好 (x, y) 对，学的是映射 f(x)→y。
强化学习是 「打游戏刷分」，没有标准答案，只有好坏信号 (reward)，靠反复试错摸出门道。

SL 监督学习
  • 数据：(输入, 标签) 对
  • 目标：最小化预测误差
  • 反馈：每步都有「正确答案」
  • 类比：考前刷真题
RL 强化学习
  • 数据：(状态, 动作, 奖励) 序列
  • 目标：最大化累计回报
  • 反馈：只有「做得好不好」
  • 类比：下棋赢了才加分
02

核心循环：Agent 和 Environment 怎么「对话」？

THE AGENT–ENVIRONMENT LOOP

在时刻 t，Agent 看到状态 st，按策略 π 选动作 at，环境给出奖励 rt+1 和新状态 st+1。循环往复。

这是强化学习里出现频率最高的一张图 —— 来自 Sutton & Barto 教材第 3 章。
目标 maxπ Eτ~π [ Σt=0T γt · rt+1 ]
回报 Gt = rt+1 + γ·rt+2 + γ²·rt+3 + … (0 ≤ γ < 1)
03

3 个关键公式：把"学习价值"这件事讲明白

VALUE & BELLMAN

RL 里几乎所有算法都在算/优化下面这 3 个量。

状态价值STATE VALUE
在策略 π 下，从状态 s 出发能拿到的期望累计回报。 Vπ(s) = Eπ [ Gt | st = s ]
动作价值ACTION VALUE
在状态 s 选动作 a 之后，再按 π 走能拿到的期望累计回报。 Qπ(s,a) = Eπ [ Gt | st=s, at=a ]
贝尔曼最优方程BELLMAN OPTIMALITY
递归关系：Q* = 立即奖励 + 折扣后最优未来价值。RL 一切算法的根。 Q*(s,a) = E [ r + γ · maxa' Q*(s',a') ]
04

三大方法族：学什么、怎么学

VALUE-BASED · POLICY-BASED · ACTOR-CRITIC

不同算法其实都在解决同一道题 —— 怎样让 Q 或 π 变得更好。按"学什么"分成 3 个家族：

方法族 核心思路 代表算法
Value-based值
学 Q 再选动作
 维护一张 Q 表 / Q 网络，
选动作时取 argmaxa Q(s,a)		 Q-Learning · DQN · Double DQN
Policy-based策
直接学 π_θ
 把策略参数化 πθ(a|s)，
直接用梯度上升优化期望回报		 REINFORCE · TRPO · PPO
Actor-Critic合
两者结合
 Actor 选动作，Critic 估价值，
用价值当 baseline 降方差		 A2C · A3C · SAC · TD3
05

新手最容易踩的 4 个坑

COMMON PITFALLS
✗
上来就上 PPO / SAC 👉 先从简单算法打 baseline。CartPole 用 DQN / 交叉熵就够，稀疏奖励场景再考虑 PPO。
✗
指望几步就能看到回报 👉 RL 试错成本高，先看 reward 曲线是否上升，再考虑调超参；用 random baseline 校准。
✗
忽视探索 (exploration) 👉 ε-greedy / 熵正则不能省，否则策略会卡在局部最优，前期表现看起来"还行"但再也上不去了。
✗
Reward 设计越复杂越好 👉 稀疏 reward + 合理 shaping > 复杂 reward；小心 reward hacking（智能体钻规则的漏洞）。
