01

条形统计图（Bar Chart）

Bar Chart

用 直条的长短 表示数量多少的统计图。看高低就比多少，最直观。

优点：很容易看出各种数量的多少
⚑ 画图注意
  • 直条的宽窄必须相同（高度才表示数量）
  • 取一个单位长度表示多少，要根据具体情况确定
  • 横轴：类别；纵轴：数量 + 单位
  • 必须有标题，标清横纵轴含义
复式 多个项目对比
  • 用不同线条或颜色区别不同项目的直条
  • 在制图日期下面注明图例
  • 适合：同类不同阶段 / 多组并列比较
📊 条形图示意（5 个班级的图书数量）
02

折线统计图（Line Chart）

Line Chart

用一个单位长度表示一定的数量，根据数量的多少描出各点，然后把各点用线段顺次连接起来。

优点：不但可以表示数量的多少，而且能够清楚地表示出数量增减变化的情况
↗ 擅长表达
  • 数量多少（点的高度）
  • 增减变化（线的斜率）
  • 长期 趋势（上升 / 下降 / 波动）
  • 适合时间序列数据（年/月/日）
⚑ 画图注意
  • 横轴表示不同时间时，间距按实际时间间隔确定
  • 不是"等距画点"！—— 比如 1 月、3 月、6 月 的点要按月份距离画
  • 数据点要标清楚，必要时连虚线辅助
📈 折线图示意（某商品 1-6 月销量变化）
03

扇形统计图（Pie Chart）

Pie Chart

用 整个圆的面积表示总数（即 100%），用 扇形面积表示各部分所占总数的百分数。

优点：很清楚地表示出各部分同总数之间的关系（看占比）
⚑ 看图注意
  • 各部分百分数加起来 = 100%
  • 扇形圆心角 = 360° × 该部分百分数
  • 不同部分用不同颜色或图案区别
  • 标清楚图例 + 每部分的百分比
↻ 擅长表达
  • 各部分 占总数的比例
  • 单一时刻的 结构 / 构成
  • 不擅长：数量多少、变化趋势
  • 适合：成分占比（家庭支出 / 土地用途 / 班级构成）
🥧 扇形图示意（家庭月支出构成，共 5000 元）
04

三种统计图对比

Bar vs Line vs Pie
图 类 核心特征 主 要 优 点 适用场景
条形 用直条长短表示数量 很容易看出各种数量的多少 同类事物的数量比较（5 班人数 / 各地区产量）
折线 用点的位置 + 连线表示变化 表示数量多少 + 增减变化情况 同一事物随时间的变化趋势（月度销量 / 气温变化）
扇形 用圆面积表示部分与整体 清楚表示各部分与总数的关系 表示各部分占总数的百分比（支出构成 / 人口结构）

💡 简单记：比多少 → 条形；看变化 → 折线；看占比 → 扇形。

05

怎么选？3 步决策法

How to Pick

面对一组数据，先问自己：想表达什么？ —— 数量、变化、还是占比？

A 5 个班的人数

想看各班多少？比大小？→ 条形图

B 月度销量变化

想看涨跌趋势？→ 折线图

C 家庭支出构成

想看占比？→ 扇形图

⚠

4 大常见误区

Common Mistakes
✗
条形图的直条宽窄不一
宽窄必须相同！只有高度才表示数量，宽度变化会误导
✗
折线图横轴等距画，不按实际时间间隔
按实际年份/月份距离画！1月、3月、6月 的间距要按月份比
✗
扇形图各部分百分数相加 ≠ 100%
所有部分加起来必须 = 100%（总是一个完整的圆）
✗
复式条形图用同一颜色，忘记加图例
不同项目用不同颜色/线条，并标图例（在制图日期下方）
