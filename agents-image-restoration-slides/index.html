Agents for Image Restoration

最近工作调研 · 2024-2026 从“单模型复原”到“可规划、可调用工具、可自进化”的 restoration agent

数据源: arXiv + OpenAlex + DBLP筛选: 953 raw → 499 dedup → 27 相关工作键盘: ← / → / Space

TL;DR · 这个方向正在发生什么

核心变化

  • 过去: 一个模型处理一种/多种退化
  • 现在: MLLM/agent 先诊断退化, 再规划工具链
  • 趋势: restoration 变成 decision-making problem

代表路线

  • RestoreAgent: MLLM autonomous planner
  • Q-Agent/Restore-R1: quality feedback + RL
  • MoA-VR/VQ-Jarvis: video agent
  • EvoIR/Self-Evolving: experience memory
一句话: Image Restoration Agent = 感知退化 + 规划顺序 + 调用专家模型 + 质量评价 + 迭代修正 的闭环系统。

为什么 Image Restoration 需要 Agent?

退化是混合的

  • 真实图像常同时有 noise / blur / rain / low-light / compression
  • 单一模型很难知道“先去噪还是先去模糊”

目标是主观的

  • 同一张图可以追求自然、清晰、人像美化或下游检测
  • 指令式 restoration 让用户意图进入系统

工具很多

  • 专用 denoiser/deblurrer/SR/LLIE 模型各有强项
  • Agent 可以像医生一样诊断 + 开处方

范式迁移: Model → Pipeline → Agent

1. Single Model

  • 输入 → 恢复
  • 任务固定
  • 评价靠 PSNR/SSIM

2. All-in-One Pipeline

  • 多退化统一模型
  • prompt/task token
  • 仍然多为一次前向

3. Agentic System

  • 先诊断再行动
  • 可调用多个专家模型
  • 可根据质量反馈迭代

评价指标正在变化

传统指标

  • PSNR / SSIM
  • LPIPS / FID
  • NIQE / BRISQUE

MLLM 感知反馈

  • 质量是否自然?
  • 是否过度锐化?
  • 是否符合用户指令?

下游任务指标

  • 检测/分割准确率
  • 自动驾驶/遥感任务效果
  • 人像主观偏好

为什么 2025-2026 RL 变多?

问题

  • restoration 没有唯一正确答案
  • PSNR 高不一定主观好
  • 工具调用顺序是离散决策

RL 的作用

  • 把 MLLM/IQA/human preference 变成 reward
  • 学习何时停止、何时重做、选哪个工具
  • 让 agent 从手写流程变成可优化 policy

Multi-Agent 为什么有吸引力?

分工清晰

  • diagnoser
  • planner
  • restorer
  • critic

降低单点失败

  • 一个 agent 错了, critic 可纠偏
  • 多个候选 restoration 可投票/融合

适合复杂场景

  • video frame consistency
  • 区域差异
  • 多目标偏好

Video Restoration Agent: 新挑战

比 image 多什么?

  • 时间一致性
  • 运动估计/遮挡
  • 帧间信息检索
  • 计算成本大幅上升

代表方向

  • MoA-VR: mixture-of-agents for all-in-one video restoration
  • VQ-Jarvis: retrieval-augmented video restoration agent
  • EDVR 等传统 video restoration 可作为 tool

Instruction-based Restoration: 从“修好”到“按我说的修”

能力

  • 用户指定区域、程度、风格
  • “保留纹理但降低噪声”这类软约束
  • retouching 与 restoration 开始融合

代表工作

  • InstructIR
  • InstructRestore
  • RetouchIQ
  • PaAgent

Self-Evolving Agent: 方向很热, 但也最难

想解决什么

  • 每次失败都沉淀经验
  • 对新退化自动形成处理策略
  • 从 rule-based planner 走向 learned planner

主要风险

  • 经验库污染/错误记忆
  • 评估器偏差放大
  • 离线 benchmark 好, 真实交互未必稳

当前主要 open problems

科学问题

  • 退化诊断是否可靠?
  • 工具顺序是否可解释?
  • MLLM 评价是否和人类偏好一致?
  • Agent 是否真优于强 all-in-one model?

工程问题

  • 推理成本高
  • 多工具接口不统一
  • 图像多轮处理会累积 artifacts
  • benchmark 尚未标准化

可发文章 Idea A · Benchmark + Protocol

目标: CVPR/ICCV/NeurIPS Datasets & Benchmarks / TPAMI · 难度: 中

问题

  • 现有论文各用各的退化组合和评价方式
  • agent 是否真的“会规划”缺少统一测试

技术路径

  • 构造 mixed degradation + instruction + tool budget benchmark
  • 记录每一步 action trace
  • 同时评估 image quality / instruction following / cost

为什么能发

  • 方向新但 benchmark 缺口明显
  • 可复现性强
  • 能成为后续 agent 论文公共平台

Idea B · Degradation Diagnosis as Test-Time Reasoning

目标: CVPR/ICCV/ECCV · 难度: 中-高

问题

  • 真实图像退化不可见
  • agent 第一步诊断错, 后面全错

技术路径

  • 把诊断写成 structured reasoning
  • 用 synthetic + real paired data 训练 verifier
  • 输出 uncertainty, 不确定时请求更多 evidence

为什么能发

  • 连接 low-level vision 与 VLM reasoning
  • 可解释, 可做 ablation
  • 能直接提升 tool selection

Idea C · Learned Tool Routing with Budget Constraint

目标: CVPR / MLSys / TPAMI · 难度: 中

问题

  • 多工具 agent 很慢
  • 不是每张图都需要复杂 pipeline

技术路径

  • 把 restoration tool 当 action set
  • reward = quality gain - latency cost
  • 训练 early-stop / cheap-first policy

为什么能发

  • 实用价值强
  • 能和任意工具箱组合
  • 适合边缘部署/自动驾驶场景

Idea D · Memory-Augmented Self-Evolving IR Agent

目标: NeurIPS / ICLR / CVPR · 难度: 高

问题

  • 自进化 agent 容易记错经验
  • 不同退化/内容的经验迁移不稳定

技术路径

  • case memory: degradation embedding + action trace + quality delta
  • 检索相似失败案例
  • 用 verifier 过滤坏经验

为什么能发

  • 契合 agent memory 热点
  • 比单次推理 agent 更进一步
  • 可做长期学习实验

Idea E · Downstream-Aware Restoration Agent

目标: CVPR / ICCV / ICRA / T-ITS · 难度: 中-高

问题

  • 视觉好看不等于检测/识别更好
  • 自动驾驶/遥感/医学更关心下游任务

技术路径

  • reward 加入 detector/segmenter confidence
  • agent 针对下游任务选择 restoration 强度
  • 做 task-aware benchmark

为什么能发

  • JarvisIR 已显示场景价值
  • 可结合用户现有农产品识别筛选场景
  • 应用落地明确

如果要快速切入, 我建议的优先级

结论

研究判断

  • 2024 是 RestoreAgent/Instruction 起点
  • 2025 开始多 agent、quality feedback、RL
  • 2026 关键词是 self-evolving、joint optimization、domain/video agent

行动建议

  • 做论文: 先做 benchmark 或 budgeted routing
  • 做系统: 先搭 tool-calling MVP
  • 做应用: 结合下游识别/检测指标, 不只看 PSNR
最终目标不是“让大模型修图”, 而是让系统知道 该修哪里、怎么修、修到什么程度、何时停止。
