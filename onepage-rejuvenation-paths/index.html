01

核心思想:从"抗衰"到"逆转"

ANTI-AGING vs REJUVENATION

抗衰: 让衰老慢一点(80 岁身体像 60 岁)。
再年轻化: 让生物年龄真正回退(60 岁身体像 40 岁)。

ANTI-AGING 抗衰 (慢下来)
  • 目标: 降低衰老速度
  • 方法: CR、雷帕霉素、NAD+
  • 效果: 延长健康寿命
  • 成熟度: 已有临床证据
REJUVENATION 再年轻化 (倒回去)
  • 目标: 让生物年龄数值变小
  • 方法: 重编程、Senolytics
  • 效果: 逆转已发生的损伤
  • 成熟度: 动物已验证, 人在路上

5 大主流技术路线

FIVE TECHNICAL ROUTES

目前最被看好的 5 条路径, ★ 越多 = 离人体临床越近:

🧹 清除衰老细胞 ★★ 临床中
Senolytics: 用小分子药物选择性杀死衰老细胞, 不伤健康细胞。
D + Q (Dasatinib + Quercetin)
人体小试进行中; 暂无寿命数据。
🔄 部分重编程 ★ 动物验证
Yamanaka 因子短期表达, 把表观遗传时钟重置, 不回到干细胞。
OSK (Oct4 + Sox2 + Klf4)
长期表达会致畸胎瘤, 时间窗需精确。
🧬 基因治疗 ★ 动物验证
AAV 递送长寿基因, 长期表达。Sirt6 过表达小鼠延寿 20%+。
AAV-Sirt6 / AAV-TERT
不可逆, 价格贵, 致癌风险待评估。
💧 血液 / 血浆因子 ★ 早期
年轻血浆 / 异体共生: 鉴定关键年轻因子 (GDF11, TIMP2), 单独补充。
GDF11 · TIMP2 · klotho
哪些因子是真正关键还没定论。
⚡ NAD+ 恢复 ★★ 已上市
补充 NAD+ 前体 (NMN/NR) 重新激活 Sirtuins 家族, 修复 DNA。
NMN / NR / NRH
动物效果有, 人体延寿证据几乎为零。

05

新手最常踩的 4 个坑

COMMON PITFALLS
✗
"再年轻化 = 抗衰" 👉 抗衰是慢下来, 再年轻化是回退。后者需要的不是药物, 是能逆转已发生损伤的技术, 难度高一个数量级。
✗
"实验室有效果 = 马上能用" 👉 小鼠延寿 ≠ 人体延寿。从动物到人体一般需要 10-15 年 + 数十亿美元。Senolytics 也只是"开始小试"。
✗
"重编程 = 完美解药" 👉 长期表达 Yamanaka 因子 = 致畸胎瘤。如何精准控制时间窗和组织特异性, 是目前最大难题。
✗
"NMN / 补剂 = 抗衰万能药" 👉 补剂市场过度营销。NMN 老鼠延寿数据 ≠ 人体数据, FDA 也未批准任何"延寿"适应症。
