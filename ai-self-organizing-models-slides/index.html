AI 自组装 / 自组织模型

从固定架构到模块、细胞、专家与 Agent 的动态组合

  • 关键词: modular self-organization, neural cellular automata, model assembly, self-growing architectures, multi-agent self-organization
  • 操作: ←/→ 或 Space 翻页, P 打印
一句话结论 · 02/33

它不是一个统一学派, 而是一组正在汇合的路线

真正的研究问题是: 模型结构、计算路径、模块分工能否由局部规则和任务反馈自动形成。

  • 最成熟: Mixture-of-Experts / conditional computation
  • 最像“自组装”: Neural Cellular Automata / neural developmental programs
  • 最接近可发新方向: LLM/Agent 的动态模块组合 + 自组织协作
主题地图 · 03/33

四条主线

把“自组装模型”拆成可检索、可投稿的 4 个英文方向。

A. Neural Cellular Automata

局部规则长出全局形态

B. Self-growing / developmental networks

网络结构随任务生长

C. Modular assembly / routing

模块、专家、工具按需组合

D. Multi-agent self-organization

多 Agent 局部互动形成协作结构

路线 A · 04/33

Neural Cellular Automata

每个 cell 只看邻域, 用共享小网络更新状态, 多步迭代后形成目标图像、纹理或动力学。

  • 代表作: Growing Neural Cellular Automata, Distill 2020, Mordvintsev et al., 184引(OpenAlex)
  • 核心机制: local perception → stochastic update → repeated growth
  • 为什么像自组装: 没有全局控制器, 结构从局部交互涌现
NCA 机制图 · 05/33

局部规则如何长成整体

同一个小模型复制到每个位置, 像细胞一样并行更新。

输入/状态
→
局部规则/路由
→
动态结构
→
全局反馈
  • Cell state: hidden channels + visible RGB/feature
  • Perception: Sobel/Laplacian/neighbor readout
  • Update rule: small MLP/CNN
  • Training signal: final morphology loss + damage recovery loss
NCA 后续 · 06/33

从图像生长到物理/硬件/科学建模

2022-2024 后 NCA 开始扩展到各类时空系统。

  • Growing Isotropic Neural Cellular Automata, ALIFE 2022
  • Hierarchical Neural Cellular Automata, ALIFE 2023
  • Neural cellular automata for solidification microstructure modelling, CMAME 2023
  • Deep learning with photonic neural cellular automata, Light: Science & Applications 2024
路线 B · 07/33

Neural developmental programs

把神经网络本身看成一个“发育体”: 从少量种子节点/模块出发, 通过规则生成完整网络。

  • 代表作: Towards Self-Assembling Artificial Neural Networks through Neural Developmental Programs, ALIFE 2023
  • 核心: genotype/program → developmental steps → phenotype/network
  • 优势: 压缩架构描述, 具备重用、生长、形态搜索潜力
  • 难点: 可训练性、稳定性、规模化到 Transformer 仍未成熟
路线 B2 · 08/33

Self-growing / continual networks

不是一次性设计固定网络, 而是在新任务到来时扩展结构。

  • Progressive Neural Networks: 旧列冻结, 新任务加新列, 横向连接迁移知识
  • Dynamically Expandable Networks: 新任务触发新单元, 兼顾灾难遗忘
  • Lifelong learning with deep neural network self-organization, Neural Networks 2017, 134引
  • 核心评价: 新任务性能、旧任务保持、参数增长率
路线 C · 09/33

Modular neural networks

把模型拆成可复用模块, 再由任务或输入决定组合方式。

  • Neural Module Networks: 语言/问题解析成模块组合
  • End-to-End Module Networks for VQA, ICCV 2017, 498引
  • Learning to Assemble Neural Module Tree Networks for Visual Grounding, ICCV 2019, 295引
  • 关键词: compositionality, module routing, structure induction
模块组装的核心 · 10/33

Assembly = 选择 + 连接 + 执行

自组装感来自“结构不是人工固定, 而是被动态生成”。

输入/状态
→
局部规则/路由
→
动态结构
→
全局反馈
  • 选择: 从 module library 中选出需要的模块
  • 连接: 生成 tree/graph/DAG 计算结构
  • 执行: 按结构调用模块并反传训练
  • 反馈: 任务 loss / reward 更新模块和路由器
路线 C2 · 11/33

Mixture-of-Experts

MoE 是当前工业界最成熟的“动态模块自组织”形态。

  • Outrageously Large Neural Networks: Sparsely-Gated MoE, 2017, 268引
  • GShard, ICLR 2021, 49引
  • Switch Transformer, 2021/2022 体系, 大规模 sparse activation
  • DeepSeekMoE, ACL 2024, 191引(OpenAlex)
  • 关键: router 学会把 token 分配给专家
MoE 为什么重要 · 12/33

它把自组装推进到大模型工程

MoE 不一定叫 self-assembly, 但它是“计算路径自动组装”的主流实现。

输入/状态
→
局部规则/路由
→
动态结构
→
全局反馈
  • 局部输入 token → router → expert subset → output merge
  • 稀疏激活: 参数很多, 每次只用少数专家
  • 研究问题: expert specialization, load balance, routing collapse, inference serving
  • 可延伸: 专家自动生成/合并/淘汰, 而不只是固定专家池
路线 D · 13/33

Multi-agent self-organization

多个 Agent 根据局部观测、通信和奖励形成分工。

  • 相关基础: Multi-agent deep reinforcement learning survey, Artificial Intelligence Review 2021, 830引
  • 典型机制: decentralized execution, communication learning, role assignment
  • Agent 系统新变化: LLM agents + tools + memory + debate + planner
  • 研究问题: 自动分工、通信协议涌现、团队结构自适应
多 Agent 图 · 14/33

从中心编排到自组织协作

传统 pipeline 是人工写死; 自组织系统让角色、调用顺序和通信拓扑随任务变化。

输入/状态
→
局部规则/路由
→
动态结构
→
全局反馈
  • Centralized: planner → worker1/worker2 → judge
  • Self-organizing: agents bid/route/negotiate form temporary team
  • 关键指标: task success, communication cost, robustness, role diversity
  • 风险: 回音室、无效通信、责任不可追踪
统一视角 · 15/33

自组装 AI = 局部规则 + 动态结构 + 全局目标

四条路线可以用同一个抽象框架描述。

输入/状态
→
局部规则/路由
→
动态结构
→
全局反馈
  • State: cell/module/expert/agent 的内部状态
  • Local rule: 更新、路由、通信、扩展规则
  • Environment/task: 输入分布与反馈信号
  • Selection pressure: loss/reward/latency/cost
  • Emergent structure: 形态、架构、专家分工、协作网络
时间线 · 16/33

2016-2026 的发展脉络

从模块化推理到大规模专家, 再到 Agent 自组织。

  • 2016: Learning to Compose Neural Networks for QA
  • 2017: End-to-End Module Networks; Sparsely-Gated MoE; Progressive Networks
  • 2020: Growing Neural Cellular Automata
  • 2021: GShard / Switch Transformer / MADRL survey
  • 2023: Neural Developmental Programs; Hierarchical NCA
  • 2024-2026: DeepSeekMoE, LLM agent teams, dynamic tool/model composition
代表工作 1 · 17/33

Growing Neural Cellular Automata

Mordvintsev, Randazzo, Niklasson, Levin · Distill 2020

  • 贡献: 用可微局部更新规则让图像从 seed 生长并可损伤恢复
  • 启发: 模型可被看作“发育过程”而不是静态函数
  • 局限: 主要是小尺度形态/纹理, 距离语言/推理任务较远
代表工作 2 · 18/33

Neural Developmental Programs

Najarro, Sudhakaran, Risi · ALIFE 2023

  • 贡献: 探索人工神经网络的自组装发育程序
  • 启发: 用程序生成网络, 可能比直接搜索权重/拓扑更可泛化
  • 局限: 还偏 ALife/探索性, ML 主流 benchmark 覆盖不足
代表工作 3 · 19/33

End-to-End Module Networks

Hu, Andreas, Rohrbach, Darrell, Saenko · ICCV 2017

  • 贡献: 将视觉问答拆成可组合神经模块, 端到端训练
  • 启发: 结构化计算图可由输入语义生成
  • 局限: 模块库设计仍需人工先验, 泛化依赖解析质量
代表工作 4 · 20/33

Sparsely-Gated MoE / Switch / GShard

Shazeer 2017 → Google MoE 系列

  • 贡献: 让模型按 token 动态选择专家, 扩展到超大参数规模
  • 启发: 自组织分工可在大模型中自然发生
  • 局限: 路由稳定性、负载均衡、部署成本是硬问题
代表工作 5 · 21/33

DeepSeekMoE

Dai et al. · ACL 2024

  • 贡献: 强调 ultimate expert specialization, 对 MoE 专家粒度和共享专家做改进
  • 启发: 专家不是均质层, 而应形成细粒度专业化
  • 可延伸: 专家出生/合并/淘汰, 形成真正生命周期
研究空白 · 22/33

为什么还没形成统一的“自组装模型”学派

因为现有路线各自解决了一部分。

可发文章 idea
  • NCA: 自组装很纯, 但任务规模小
  • Growing networks: 会生长, 但规则常是人工阈值
  • Module networks: 可组合, 但模块库和结构先验强
  • MoE: 工程成熟, 但专家池通常固定
  • Multi-agent: 很像自组织, 但缺少可复现标准与稳定训练
可发方向 A · 23/33

Self-growing MoE: 专家生命周期

把固定专家池变成可出生、分裂、合并、死亡的生态系统。

可发文章 idea
  • 目标: NeurIPS / ICML / ICLR / ACL Findings
  • 方法: routing entropy + specialization score + load/cost 触发 expert split/merge
  • 实验: language modeling + multi-domain adaptation + continual learning
  • 卖点: 从 sparse activation 走向 adaptive sparse architecture
可发方向 B · 24/33

NCA for representation learning

让特征图像/latent token 通过局部规则自组织, 而不是只生长 RGB 图案。

可发文章 idea
  • 目标: ICLR / CVPR / ALIFE
  • 方法: NCA update on latent grid / token grid, 与 ViT/UNet 结合
  • 实验: few-shot segmentation, image restoration, diffusion latent refinement
  • 卖点: 局部规则 + 可损伤恢复 + 空间泛化
可发方向 C · 25/33

Agent team self-assembly

给任务后, 系统自动形成临时团队、通信拓扑和职责分配。

可发文章 idea
  • 目标: ACL / EMNLP / ICLR Agent workshop / AAMAS
  • 方法: role proposal → bidding → dynamic graph communication → judge
  • 实验: software engineering, literature review, data analysis, tool-use benchmark
  • 卖点: 比固定 planner-worker 更鲁棒、更低通信成本
可发方向 D · 26/33

Model assembly compiler

把“模型自动组合”做成编译器: 任务规范 → 模块图 → 执行计划。

可发文章 idea
  • 目标: MLSys / NeurIPS Datasets & Benchmarks / ACL System
  • 模块: LLM, retriever, vision model, tool, verifier, memory
  • 优化目标: accuracy, latency, cost, privacy
  • 卖点: 面向真实应用的可解释自动组装
实验设计 · 27/33

最小可跑 baseline

如果要开题, 建议先做一个小而完整的系统。

  • 任务: 多领域分类/问答/图像修复三选一
  • 模块库: 4-8 个专家/工具/子模型
  • 路由器: learned router + rule router + random router 对照
  • 自组织机制: split/merge 或 dynamic team formation
  • 指标: performance, cost, specialization, robustness
评价指标 · 28/33

不要只看 accuracy

自组织模型必须证明“结构真的变好了”。

  • Performance: 任务成功率/准确率
  • Efficiency: FLOPs, latency, token cost, active modules
  • Specialization: expert entropy, mutual information, domain purity
  • Adaptivity: 新任务迁移速度, 参数增长率
  • Robustness: 模块失效/噪声/分布漂移下的退化
推荐命名 · 29/33

论文标题怎么包装更容易被接受

少用中文直译 self-assembly model, 多用主流关键词。

  • Adaptive Modular Self-Organization for ...
  • Self-Growing Mixture-of-Experts for Continual ...
  • Dynamic Model Assembly for Tool-Augmented ...
  • Neural Developmental Programs for ...
  • Self-Assembling Agent Teams for ...
投稿地图 · 30/33

不同路线对应不同 venue

选 venue 取决于你强调理论、模型、系统还是应用。

  • ICLR/NeurIPS/ICML: 新模型机制 + benchmark
  • ACL/EMNLP: LLM agents, tool/model composition, routing
  • CVPR/ICCV/ECCV: NCA for vision, restoration, segmentation
  • AAMAS: 多 Agent 自组织和协作
  • ALIFE/Natural Computing: 发育式 AI、形态计算、NCA 理论
风险清单 · 31/33

这方向容易踩的坑

最大风险不是没有方向, 而是概念太大、实验太散。

  • 概念风险: self-assembly 听起来新, 但 reviewer 会问和 MoE/NAS/agents 有何区别
  • 实验风险: 动态结构带来的收益可能来自参数更多
  • 工程风险: split/merge 会破坏训练稳定性
  • 叙事风险: 生物类比太多, 技术贡献不足
结论 · 32/33

值得做, 但要选一个窄切口

最推荐的 3 个切口。

  • 快出活: Self-growing MoE / expert lifecycle
  • 有新意: NCA + latent representation / restoration
  • 贴近大模型应用: Self-assembling agent teams / model assembly compiler
  • 一句话: 不要做泛泛的“自组装模型”, 要做可评测的“动态模块自组织机制”。
