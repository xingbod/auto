02
技术架构：智能体如何"看诊"AGENT ARCHITECTURE
🧠 基础模型 + 医学微调
GPT-4 / Med-PaLM / 百川 等大模型经医学语料 (论文、病历、考试题) 继续训练或 RLHF，掌握临床推理链 (Chain-of-Thought Diagnosis)。
📚 RAG 医学知识检索
外挂医学知识库 (PubMed、UpToDate、药品说明书、临床指南)，动态检索最新证据，降低幻觉。医渡云 300 亿级医学知识图谱即此范式。
🤝 多智能体协作 (Multi-Agent)
一个"分诊 Agent"初筛 → "专科 Agent"深入 → "审核 Agent"校验 → "报告 Agent"生成。AMIE 的自我博弈对话训练即此思路。
👁️ 多模态融合
影像 (CT/MRI/X 光) + 文本 (病历/检验报告) + 基因组数据联合推理。Google Med-Gemini 系列已展示跨模态诊断能力。
03
核心能力矩阵CAPABILITY DEEP DIVE
🩻 影像判读 — 从"辅助"走向"主力"
眼底照片 → 糖尿病视网膜病变 (Airdoc 灵敏度 93%)；胸部 CT → 肺结节检出 (推想科技)；病理切片 → 癌细胞分割。FDA 950+ AI 设备中影像类占 75%。
💬 对话问诊 — AMIE 实现"比医生更有同理心"
2024 年 AMIE OSCE 测试：在诊断准确率持平初级保健医生 (PCP) 的前提下，患者评分在「同理心」「沟通清晰度」维度上超越人类医生。采用了自我对弈 + 模拟患者反馈的强化训练。
💊 药物发现 — AlphaFold 3 + Isomorphic Labs
AlphaFold 3 预测所有生物分子相互作用 (蛋白质/DNA/RNA/配体)。Isomorphic Labs (DeepMind 分拆) 已与 Eli Lilly、Novartis 签署数十亿美元合作，AI 设计分子进入临床前管线。
📋 病历自动化 — 医生每周节省 5-10 小时
Microsoft DAX Copilot 将医患对话实时转为结构化病历，准确率 > 95%，覆盖 200+ 美国医疗机构，带来医生满意度显著提升。

常见误判与关键挑战PITFALLS & CHALLENGES
✗
「AI 准确率 87% 就可以替代医生了」 👉 MedQA 是选择题，不等于真实临床决策。临床场景需多轮对话 + 体格检查 + 不确定性管理，Agent 目前仍是「辅助」定位。
✗
「大模型看过足够多病历就能安全看病」 👉 医学幻觉 (hallucination) 在临床场景零容忍 — 错误的诊断建议可能导致生命危险。RAG + 溯源引用 + 人机协同审核是现阶段必须的防线。
✗
「技术成熟后落地自然发生」 👉 监管 (FDA/NMPA)、数据隐私 (HIPAA/PIPL)、医院信息系统集成、医生信任度、医保支付 — 每一项都是比技术更难的「非技术壁垒」。
✗
「中国医疗 AI 落后于美国」 👉 在影像 AI (肺结节/眼底/病理)、NMPA 审批速度、医院数据规模等维度，中国具备独特优势。差距主要在基础模型原创性和全球多中心临床验证。
TL;DR · 这一页先记住
① 辅助非替代
医学 AI Agent 当前定位是"增强医生的能力"，而非"取代医生"。诊断、手术、用药等高风险决策仍需人类审核。
② Agent 化是趋势
从单一模型问答走向多 Agent 协作（分诊→专科→审核→报告），闭环自主决策的能力正在快速演进。
③ 中国窗口期
百川/讯飞/医渡云/腾讯觅影等已形成产品矩阵，数据规模 + 审批速度是优势，基础模型原创性是短板。
一句话总结：医学 AI 智能体已经通过了"考试"，正在走进"诊室"——但距离真正自主独立诊疗，至少还有 5-10 年的临床验证、监管共识和公众信任建设。
